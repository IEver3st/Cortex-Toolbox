# Product

## Register

product

## Platform

web

## Users

FiveM resource developers working locally on scripts, vehicle metadata, models, and release-ready resource packages. They need one dependable desktop workbench that makes complex relationships visible and lets them repair or generate files without leaving their project.

## Product Purpose

Get work done for their scripts or models. Cortex turns resource folders into focused, independently editable workflows for understanding code, generating metadata, diagnosing broken references, building packages, and producing FiveM-ready assets.

## Positioning

Free and Open Source while being better than everything else.

## Brand Personality

Reliable, Confident, Elegant.

## Anti-references

Cortex must not look like a neon gaming dashboard, a glassmorphic concept, a generic purple-gradient AI product, or an unfinished developer demo. Dense information should remain calm, legible, and desktop-oriented.

## Design Principles

- Make evidence visible: show what Cortex found, where it came from, and how confident the result is.
- Preview before writing: every generated or repaired file should have an understandable change plan.
- Organize by real workflow: each capability is an independently editable module backed by shared domain engines.
- Keep source local and reversible: prefer reviewed writes, explicit exports, and recoverable changes.
- Earn confidence through clarity: explain relationships and failures in language FiveM developers can act on.

## Accessibility & Inclusion

Keyboard access, visible focus, readable contrast, non-color status cues, reduced-motion support, and layouts that remain usable in compact desktop windows are baseline requirements.
